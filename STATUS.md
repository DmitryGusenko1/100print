# STATUS

## Реализовано
- Python-приложение общей памяти.
- Модели PostgreSQL: владельцы, проекты, диалоги, сообщения, решения, задачи, версии состояния.
- Дедупликация сообщений по `source + external_id`.
- FastAPI с healthcheck, добавлением сообщений, контекстом, задачами, решениями и состоянием.
- Проверка API-ключа и владельца проекта.
- Telegram-команды `/start`, `/projects`, `/project`, `/status`.
- Сохранение входящего сообщения до вызова AI.
- OpenAI-compatible AI provider.
- PostgreSQL full-text retrieval.
- Alembic migration.
- systemd units без Docker.
- Скрипты резервного копирования и восстановления.

## Ещё не проверено на VPS
- Фактическая установка зависимостей.
- Миграция на реальной PostgreSQL.
- Существующие порты, systemd services и действующие Telegram polling-процессы.
- Реальный Telegram ID владельца.
- AI API key/provider.
- Backup/restore на отдельной тестовой базе.

## Ограничение
Обычные чаты ChatGPT и Codex пока автоматически в эту память не пишутся. Это отдельный этап интеграции после запуска первого рабочего контура.
