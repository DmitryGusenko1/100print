# Frontend Design

Use for UI/UX, page implementation, visual hierarchy, design systems, and responsive behavior.

## Priorities
1. User goal and conversion.
2. Clarity of offer, price logic, and next action.
3. Fast mobile experience.
4. Accessible states and controls.
5. Consistent reusable components.
6. Visual quality without decorative clutter.

## For 100print
Prioritize product discovery, instant/assisted quotation, artwork upload, order status, repeat order, and contact with a manager.

## Required states
Design loading, empty, validation, error, success, disabled, and mobile states — not only the ideal desktop screen.

## Verification
Check responsive layouts, keyboard usability where relevant, contrast, readable typography, form errors, and actual rendered output. Do not call UI complete from code inspection alone.
